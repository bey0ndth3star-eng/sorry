# Pour Josephine 🐱

Site statique (HTML + Three.js via CDN), prêt pour GitHub Pages.

## Mise en ligne
1. Crée un dépôt GitHub (ex. `josephine`).
2. Envoie `index.html`, `.nojekyll` et `README.md` à la racine du dépôt.
3. Settings → Pages → Source : `Deploy from a branch` → `main` / `(root)` → Save.
4. Le site sera dispo sur `https://TON-PSEUDO.github.io/josephine/`.
